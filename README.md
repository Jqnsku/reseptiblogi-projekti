# Reseptiblogi-projekti
#### Figmalla suunniteltu sivu: https://www.figma.com/make/SnmEcbYHn2yckSJZCMvROw/Recipe-Blog-App?p=f ####
## Suunnitelma ##

Selkeä reseptiblogi, jossa käyttäjät voivat:
- selata uusimpia reseptejä etusivulla
- hakupalkki, jolla voi hakea reseptiä nimellä
- Käyttäjät voivat jakaa reseptejään
- avata yksittäisen reseptin omalle sivulleen
- kirjautua sisään kommentoidakseen
- käyttää sivua myös ilman kirjautumista vierailijana

## Esim. malli alkunäyttö: ##

Alkunäytössä näkyy viimeisimmät reseptit, jota klikkaamalla koko resepti aukeaa, jonka jälkeen kerrotaan enemmän ohjeista/vaiheet esim. 1,2,3... mitä vaiheita ruoanlaitossa on.

Eli alussa näkymä, missä viimeisimmät reseptit kuvan kanssa 2 kuvaa vierekkäin, jonka alla lyhyt teksti reseptistä esim: terveellinen ja nopea aamupala.

## Reseptin klikkaus => ##

Reseptiä/kuvaa painamalla aukeaa sivu,
jossa on iso kuva ruoasta. Takaisin nappi kuvan yläpuolella, josta pääsee takaisin alkunäyttöön.
